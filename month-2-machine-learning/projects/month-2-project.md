# Month 2 Project — End-to-End Predictor

Take a dataset from raw to a working, evaluated model.

## Steps
1. **Pick a dataset** with a clear target to predict (Kaggle, UCI, or seaborn's
   built-ins). Classification or regression — your choice.
2. **Explore** it: shape, missing values, distributions, a couple of plots.
3. **Clean & prepare:** handle missing values, encode categoricals, scale if needed.
4. **Train** at least two different models.
5. **Evaluate** properly: held-out test set or cross-validation, the right metrics.
6. **Report:** which model won, how well it does, and where it fails.

## Requirements
- A single notebook or script that runs start to finish.
- An evaluation section with numbers, not vibes.
- A short `README.md`: the question, the data, the result.

## Stretch goals
- Tune hyperparameters (`GridSearchCV`).
- Show a feature-importance or coefficient interpretation.
- Save the trained model and write a tiny script that loads it and predicts.

## Done when
Someone could read your report and trust (or sensibly doubt) your model's claims.
