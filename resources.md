# Resources

A lean, curated list. Don't try to read everything — these support the labs.

## Your two reference courses (the backbone)
- **Agentic AI Engineering course** — primary companion for **Month 1** (intro/API)
  and especially **Month 4** (agents, RAG, tools, deployment).
- **Hands-on Data Science & ML with Python** — primary companion for **Month 2**
  (applied ML) and **Month 5** (stats, pandas, the DS workflow).

## Building with LLMs & agents (Months 1, 4)
- Claude API docs (docs.claude.com): the Python SDK quickstart, tool use,
  structured outputs, prompt caching, and building agents.
- Ollama docs (docs.ollama.com): the local REST API, model library, and embeddings.
- MCP docs (modelcontextprotocol.io) for giving models tools.
- A vector-database quickstart (e.g. Chroma).

## Classic ML (Month 2)
- scikit-learn user guide — "Getting Started" + "Supervised learning."
- Kaggle "Intro to Machine Learning" micro-course for extra datasets.

## Deep learning (Month 3)
- PyTorch "Learn the Basics" and the "60-Minute Blitz."
- A visual/illustrated transformer explainer for intuition.

## Math & data science (Month 5)
- 3Blue1Brown — "Essence of Linear Algebra" and "Essence of Calculus" (intuition).
- Khan Academy — fill any probability/statistics gaps.
- pandas and seaborn official tutorials.

## Datasets to practice on
- seaborn built-in datasets (instant, no download).
- UCI Machine Learning Repository.
- Kaggle Datasets.

## Working habit
For every resource you consume, do the matching **lab** in that week's folder. Reading
without building is the slow path; this course is built around the opposite.
